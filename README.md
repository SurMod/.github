# SurMod

Bienvenido al GitHub de **SurMod**.

Somos un estudio que desarrolla **plugins a medida para WordPress y WooCommerce**, con integración directa en **FacturaScripts**, y las apps/webs que los acompañan — **Flutter** para móvil y **Next.js** para la web.

## A qué nos dedicamos

- **Plugins WooCommerce a medida** — desde paneles B2B para redes de agentes comerciales hasta tiendas B2C completas.
- **Integración WooCommerce ↔ FacturaScripts** — facturación automática, sincronización de stock y variantes, devoluciones como rectificativas.
- **Apps móviles con Flutter** — un único código para Android e iOS.
- **Webs headless con Next.js** — frontends rápidos sobre WooCommerce/WordPress.
- **Infraestructura** — Docker, Traefik, certificados automáticos, backups y monitorización.

## Productos

- **SuperB2B** — venta B2B para agentes comerciales y representantes.
- **SyncFactuWoo** — sincronización WooCommerce ↔ FacturaScripts.
- **SuperB2C** *(en desarrollo)* — la misma base, pensada para tiendas al público general.
